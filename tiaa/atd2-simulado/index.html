Cadastro de Funcionários com UserForm • Prof. Dr. Junior Pedro Colombo

Objetivo do simulado

Desenvolver no Excel VBA um cadastro de funcionários usando UserForm. O arquivo deverá ser salvo e enviado como Pasta de Trabalho Habilitada para Macro do Excel (.xlsm).

Importante: a correção será realizada manualmente pelo professor. O funcionamento do VBA será testado no arquivo enviado.

O que deverá funcionar

  1. Crie a planilha BANCO_FUNCIONARIOS com as colunas MATRÍCULA, NOME, CARGO e SETOR.
  2. Crie um UserForm com campos para Nome, Cargo e Setor.
  3. A matrícula deverá ser gerada automaticamente, sem digitação pelo usuário.
  4. Crie os botões Cadastrar, Limpar e Cancelar.
  5. O botão Cadastrar deverá validar os campos, gerar a próxima matrícula e gravar os dados na planilha.
  6. O botão Limpar deverá apagar apenas os campos do formulário.
  7. O botão Cancelar deverá fechar o formulário.
  8. Crie na planilha um botão ABRIR CADASTRO DE FUNCIONÁRIOS para abrir o UserForm.
  9. Antes do envio, faça pelo menos três cadastros de teste e confirme a sequência das matrículas.
