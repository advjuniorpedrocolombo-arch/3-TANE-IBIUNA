3. Código do botão CADASTRAR

Private Sub btnCadastrar_Click()
    Dim planilha As Worksheet
    Dim linha As Long
    Dim matricula As Long

    If txtnome.Value = "" Or TxtCargo.Value = "" Or TxtSetor.Value = "" Then
        MsgBox "Preencha todos os campos antes de cadastrar.", _
               vbExclamation, _
               "Campos obrigatórios"
        Exit Sub
    End If

    Set planilha = Sheets("BANCO_FUNCIONARIOS")
    linha = planilha.Cells(planilha.Rows.Count, 1).End(xlUp).Row + 1

    If linha = 2 Then
        matricula = 1
    Else
        matricula = planilha.Cells(linha - 1, 1).Value + 1
    End If

    planilha.Cells(linha, 1).Value = matricula
    planilha.Cells(linha, 2).Value = txtnome.Value
    planilha.Cells(linha, 3).Value = TxtCargo.Value
    planilha.Cells(linha, 4).Value = TxtSetor.Value

    MsgBox "Funcionário cadastrado com sucesso!" & vbCrLf & vbCrLf & _
           "Matrícula: " & matricula, _
           vbInformation, _
           "Cadastro realizado"

    txtnome.Value = ""
    TxtCargo.Value = ""
    TxtSetor.Value = ""
    txtnome.SetFocus
End Sub

Esse código verifica se todos os campos foram preenchidos, cria a próxima matrícula, grava Nome, Cargo e Setor na planilha e mostra uma mensagem com a matrícula gerada.

4. Código do botão LIMPAR

Private Sub btnLimpar_Click()
    txtnome.Value = ""
    TxtCargo.Value = ""
    TxtSetor.Value = ""
    txtnome.SetFocus
End Sub

Esse botão apaga apenas o que está digitado no formulário. Ele não apaga os dados já cadastrados na planilha.

5. Código do botão CANCELAR

Private Sub btnExcluir_Click()
    Unload Me
End Sub

Esse botão fecha o formulário.

6. Criando o botão para abrir o formulário

No Editor do VBA, clique em Inserir > Módulo e digite:

Sub AbrirCadastro()
    UserForm1.Show
End Sub

Volte para a planilha BANCO_FUNCIONARIOS. Na guia Inserir, escolha uma Forma, escreva ABRIR CADASTRO DE FUNCIONÁRIOS, clique com o botão direito sobre a forma, escolha Atribuir Macro e selecione AbrirCadastro.

7. Testando o cadastro

  1. Abra o formulário.
  2. Digite um nome, um cargo e um setor.
  3. Clique em Cadastrar.
  4. Confira se a matrícula foi criada automaticamente.
  5. Confira se os dados apareceram na planilha BANCO_FUNCIONARIOS.
  6. Faça mais dois cadastros e observe a sequência das matrículas.
  7. Teste também os botões Limpar e Cancelar.

Resultado esperado: o sistema deverá cadastrar os funcionários em sequência usando as colunas MATRÍCULA, NOME, CARGO e SETOR.

O que deverá funcionar

  1. Planilha BANCO_FUNCIONARIOS com MATRÍCULA, NOME, CARGO e SETOR.
  2. UserForm com campos Nome, Cargo e Setor.
  3. Matrícula gerada automaticamente.
  4. Botões Cadastrar, Limpar e Cancelar funcionando.
  5. Botão na planilha para abrir o cadastro.
  6. Pelo menos três cadastros de teste com sequência correta das matrículas.
