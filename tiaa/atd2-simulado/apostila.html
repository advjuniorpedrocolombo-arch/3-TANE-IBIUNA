Cadastro de Funcionários com UserForm

Apostila prática — passo a passo

← Voltar para a ATD2

Objetivo

Criar um formulário simples no Excel VBA para cadastrar funcionários, gerar a matrícula automaticamente, limpar os campos e fechar o formulário.

1. Criando a planilha

Crie uma nova pasta de trabalho do Excel e salve como Pasta de Trabalho Habilitada para Macro do Excel (*.xlsm).

Renomeie a planilha para BANCO_FUNCIONARIOS.

MATRÍCULANOMECARGOSETOR
1ExemploGerenteMarketing

Importante: a matrícula não será digitada no formulário. Ela será criada automaticamente pelo VBA.

2. Criando o formulário

Pressione ALT + F11 para abrir o Editor do VBA. Depois clique em Inserir > UserForm.

No formulário, crie três campos:

CampoName do TextBox
Nometxtnome
CargoTxtCargo
SetorTxtSetor

Crie também três botões:

Texto do botãoName do botão
CadastrarbtnCadastrar
LimparbtnLimpar
CancelarbtnCancelar

Observação: no modelo atual, o botão com o texto “Cancelar” está com o Name btnExcluir. Vamos manter esse nome porque o código já está funcionando.

3. Código do botão CADASTRAR

Dê dois cliques no botão Cadastrar e cole o código abaixo:

Private Sub btnCadastrar_Click()
    Dim planilha As Worksheet
    Dim linha As Long
    Dim matricula As Long

    If txtnome.Value = "" Or TxtCargo.Value = "" Or TxtSetor.Value = "" Then
        MsgBox "Preencha todos os campos antes de cadastrar.", _
               vbExclamation, _
               "Campos obrigatórios"
        Exit Sub
    End If

    Set planilha = Sheets("BANCO_FUNCIONARIOS")
    linha = planilha.Cells(planilha.Rows.Count, 1).End(xlUp).Row + 1

    If linha = 2 Then
        matricula = 1
    Else
        matricula = planilha.Cells(linha - 1, 1).Value + 1
    End If

    planilha.Cells(linha, 1).Value = matricula
    planilha.Cells(linha, 2).Value = txtnome.Value
    planilha.Cells(linha, 3).Value = TxtCargo.Value
    planilha.Cells(linha, 4).Value = TxtSetor.Value

    MsgBox "Funcionário cadastrado com sucesso!" & vbCrLf & vbCrLf & _
           "Matrícula: " & matricula, _
           vbInformation, _
           "Cadastro realizado"

    txtnome.Value = ""
    TxtCargo.Value = ""
    TxtSetor.Value = ""
    txtnome.SetFocus
End Sub

Esse código verifica se todos os campos foram preenchidos, cria a próxima matrícula, grava Nome, Cargo e Setor na planilha e mostra uma mensagem com a matrícula gerada.

4. Código do botão LIMPAR

Private Sub btnLimpar_Click()
    txtnome.Value = ""
    TxtCargo.Value = ""
    TxtSetor.Value = ""
    txtnome.SetFocus
End Sub

Esse botão apaga apenas o que está digitado no formulário. Ele não apaga os dados já cadastrados na planilha.

5. Código do botão CANCELAR

Private Sub btnExcluir_Click()
    Unload Me
End Sub

Esse botão fecha o formulário.

6. Criando o botão para abrir o formulário

No Editor do VBA, clique em Inserir > Módulo e digite:

Sub AbrirCadastro()
    UserForm1.Show
End Sub

Volte para a planilha BANCO_FUNCIONARIOS. Na guia Inserir, escolha uma Forma e escreva ABRIR CADASTRO DE FUNCIONÁRIOS. Clique com o botão direito sobre a forma, escolha Atribuir Macro e selecione AbrirCadastro.

7. Testando o cadastro

  1. Abra o formulário.
  2. Digite um nome, um cargo e um setor.
  3. Clique em Cadastrar.
  4. Confira se a matrícula foi criada automaticamente.
  5. Confira se os dados apareceram na planilha BANCO_FUNCIONARIOS.
  6. Faça mais dois cadastros e observe a sequência das matrículas.
  7. Teste também os botões Limpar e Cancelar.

8. Resultado esperado

Ao final, o sistema deverá cadastrar os funcionários em sequência, usando as colunas MATRÍCULA, NOME, CARGO e SETOR.

9. Resumo

Cadastrar: valida os campos, cria a matrícula e grava os dados.
Limpar: apaga os campos do formulário.
Cancelar: fecha o formulário.
